④ 国赛 / 省赛 / 世赛三条路线的区别

这三类卷子长得完全不一样，不要拿错资料去练。

  • 世赛云计算（Skill 39/53） —— 公有云（AWS）+ 排障。四天赛程，有官方 task 编号评分体系，排错占约四分之三。练法：作战台 · 里昂 2024 仿真场世界赛
  • 国赛 / 省赛 云计算应用 —— 私有云 + 容器云 + 公有云三模块，按「模块 / 任务 / 分值」给分。练法：本页的模块与任务清单 + 实训场 L1–L4国赛
  • 金砖云计算 —— OpenStack 部署运维 / 容器云 / 自动化部署运维三模块，2 人/队实操。练法：同国赛，但更偏 OpenStack 手搓国际

判断自己在哪个赛道：看卷子是「任务书 + 分值」形式（国赛/省赛），还是「拓扑 + 工单 + 评分脚本」形式（世赛）。前者比模块分，后者比排障。
