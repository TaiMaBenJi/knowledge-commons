① 考什么 · 三分钟认清赛项

云计算项目比的是「在时间压力下，按评分细则逐项精确交付企业级云环境」——不是「会用云控制台」。典型赛程四天四模块：基础设施与网络 → 平台服务与自动化 → 故障排查 → 综合迁移与优化。评分以功能性验收为主：脚本逐项验证，做对得分，做错或没做不得分。

2026-10 实锤：上海第 48 届世赛正式设云计算赛项（Skill 53），公有云平台为 AWS；官方技术描述（TD53）明确「四天赛程中两天整日排障、两天仅下午排障」——排错占赛场时间约四分之三。官方 TD 入库：中文导读 · 英文原文 PDF

项目全貌：项目总纲（从零到精通） · 总纲课视频 · 模拟训练（十题交互评分）

官方评分权重（WSOS 2026 上海世赛职业标准，已译中文全文入库）：

  • 问题解决、创新与创造力 —— 设计分层架构、排障、迁移方案20%
  • 网络安全 —— 认证授权、加密传输、安全组与基线20%
  • 可靠性、可扩展性与弹性 —— 高可用、负载均衡、弹性伸缩15%
  • 工作组织与管理 —— 读题拆解、交付顺序、时间管理10%
  • 性能与优化 / 运营考虑因素 / 可持续性各 10%
  • 沟通与人际交往 —— 交付文档写得清楚本身就是分5%

国内怎么打上去（晋级链）：院校/单位报名 → 省市级选拔赛（各省人社部门组织的世赛选拔，职业院校技能大赛云计算赛项同向练兵）→ 全国选拔赛（中华人民共和国职业技能大赛等国家级赛事）→ 国家集训队（第 48 届云计算项目中国集训基地含山西职业技术学院、天津电子信息职业技术学院等）→ 集训多轮考核 → 国家队 → 上海 2026 世赛。

③ 一年成长路线 · 可打卡（每天 2 小时）

第 0 步 · 认知与装备（第 1 周）

读第 0 章 · 开始之前 → 读WSOS 官方标准中文版（知道权重才知道劲往哪使）→ 玩一遍模拟训练 → 按第 1 章三方案装好 Linux 练习机。验收：能说出赛项四模块、评分逻辑、五大权重。

阶段一 · 地基（第 1–2 月）｜第 1–3 章

命令 → 文件权限 → 服务管理 → 管道脚本 → SSH → 网络 → 服务器实战（Nginx/MySQL/crontab）。这三章禁止跳读，每个动手环节必须真敲。验收：不看资料，15 分钟完成一台新机的初始化、加固与网页发布。

阶段二 · 企业服务（第 3–5 月）｜第 4–9 章

HTTPS 证书 → DNS（BIND9 主从）→ 负载均衡与高可用（HAProxy/Keepalived）→ 故障排查 18 案例 → Windows Server 与 AD 域 → Shell 进阶三连。验收：独立交付含域名、证书、双节点高可用的站点，并写出部署文档。

阶段三 · 云与容器（第 6–8 月）｜第 10–12 章 + 知识地图

Docker 全套 → Kubernetes 从 minikube 到 HPA → AWS（IAM/VPC/EC2/S3/RDS/ALB/ASG）。配套读知识地图 · 容器与编排与虚拟化与私有云。验收：任一手工部署 30 分钟内脚本化重放，幂等。

阶段四 · 自动化与运维（第 9–10 月）｜第 13–15 章

Ansible → Terraform → CI/CD 一条龙 → Prometheus/Grafana 监控 → 安全加固打分。开始跑365 天训练系统（每日 2–4 小时：40 分钟精读 + 全部上机）。验收：一条龙自动化交付 + 告警可用 + 加固清单过 80%。

阶段五 · 竞赛级打磨（第 11–12 月起循环）

学第 16 章 · 黄金四步训练法 → 真题轮刷（见下方④真题地图）→ 第 20 章 · 锐捷云平台真题带练 → 每月一次全真模拟，按评分表自评、复盘归因。配套精通阶梯自测。验收：模拟赛稳定过目标线，每个失分点写得出原因与对策。

赛前一周 · 状态与纪律

重读现场十军规与72 小时冲刺手册；检查单打印上墙；只做熟题不学新东西；环境快照习惯最后演练一遍。赛程四天，体能和心理也是考点。

⑤ 怎么拿分 · 高频考点与赛场纪律

  • 幂等脚本 —— 重复执行结果一致，是自动化交付的底线考点
  • 健康检查 —— 必须探测真实服务端口与页面，不是 ping 通就算考点
  • 最小权限 —— 日常操作禁用最高权限；证书链要含中间证书考点
  • 分层排错 —— 链路 → 系统 → 服务 → 应用，逐层定位缩短 MTTR考点
  • 先通读任务与评分表，圈出验收方式再动手；按依赖排交付顺序纪律
  • 环境先拍快照；每完成一项立即按验收方式自验；变更随手记录纪律
  • 时间留二成缓冲给排错与复验；收工前全链路复验再提交纪律
