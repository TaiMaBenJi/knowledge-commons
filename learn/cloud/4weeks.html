零基础 · 4 周云计算冲刺

你不需要先懂任何东西。照天数走，每天一个可验收的产出。

先说实话：4 周零基础，不可能精通云计算。但比赛里基础操作分、部署分、排障分是能抢的—— 抢到这些分，你就不是最后一名。这个页面只做一件事：告诉你今天该做什么。

每天怎么用：① 照「做什么」动手（一定要自己敲）② 需要细节就点「读哪一节」③ 做完对照「验收」自测，过了就点当天卡片下面的「标记学完这一讲」。

第 1 周 · 先能操作（把 Linux 用起来）

第 1 天 · 装一台属于你的 Linux

做什么（1.5–2 小时）

  • 装 VMware/VirtualBox + Ubuntu Server（或直接开一台云主机、或用你电脑的 WSL），记住登录口令与 IP。
  • 打开终端，敲：whoami、hostname、ip a、ls /etc。看不懂没关系，先让手记住位置。

读哪一节：

验收：能自己开机 → 登录 → 打开终端 → 打出上面 4 条命令。

第 2 天 · 命令行生存技能

做什么（1.5–2 小时）

  • 文件操作：cd ls cp mv rm mkdir cat less；管道与重定向：| > >>。
  • 检索三件套：grep、find、wc。

读哪一节：

验收：不用鼠标完成：找出 /etc 下所有 .conf 文件并数出总数。

第 3 天 · 用户与权限（比赛必考）

做什么（1.5–2 小时）

  • useradd passwd usermod id；chmod 数字法 755/750/644；chown；sudo。
  • 建一个用户，给它一个目录的 750 权限，用该用户登录验证能不能进。

读哪一节：

验收：能解释 750 每一位代表什么；能复现一遍。

第 4 天 · 装软件：把 Nginx 装上

做什么（1.5–2 小时）

  • apt update / apt install nginx（或 dnf），记住包管理器是干什么的。
  • 浏览器访问服务器 IP，看到 Nginx 默认页。

读哪一节：

验收：换一台干净的机器，5 分钟内装上并访问成功。

第 5 天 · 服务与日志（故障排查的地基）

做什么（1.5–2 小时）

  • systemctl start/enable/status/restart；用 journalctl -u nginx 看日志。
  • 把 Nginx 设为开机自启，然后重启机器验证。

读哪一节：

验收：服务起不来时，知道先看 `systemctl status` 再看 `journalctl`。

第 6 天 · 网络基础（半小时版）

做什么（1.5–2 小时）

  • IP / 子网 / 网关 / DNS / 端口，这五个词能用自己的话解释。
  • 实操：ip a 看地址、ping 通外网、ss -tlnp 看 80 端口在监听、curl -I 看响应头。

读哪一节：

验收：能指着屏幕说清：这台机器的 IP、网关、DNS 各是多少，谁在监听 80。

第 7 天 · 第 1 周复盘（不学新东西）

做什么（1.5–2 小时）

  • 把前 6 天做过的操作，不看笔记再走一遍；卡住的地方记下来当复习点。
  • 默写常用命令 20 条。

读哪一节：

验收：能连续说出 20 条命令及其用途。

第 1 周检查：服务起不来，最先看哪里？
故障排查第一步永远是看状态和日志，不是猜配置。

第 2 周 · 能提供服务（网站 / 数据库 / 安全）

第 8 天 · 域名解析：DNS 与 hosts

做什么（1.5–2 小时）

  • 解析流程（浏览器 → hosts → DNS → IP）用自己话讲一遍。
  • 改本地 hosts 文件，把一个假域名指向你的服务器 IP。

读哪一节：

验收：能用 hosts 让 `test.local` 打到你的 Nginx。

第 9 天 · 把网站配起来（虚拟主机）

做什么（1.5–2 小时）

  • 在 /etc/nginx/ 下加一个自己的站点配置，DocumentRoot 指到你建的目录。
  • 放一个 index.html，重载 Nginx 并访问。

读哪一节：

验收：改配置 → `nginx -t` 检查 → `systemctl reload nginx` → 生效，这条链能背下来。

第 10 天 · HTTPS 与证书

做什么（1.5–2 小时）

  • 用 openssl 自签一张证书，配置 Nginx 443，并让 http 跳到 https。
  • 浏览器里点开锁图标，看证书内容。

读哪一节：

验收：能独立让一个站点跑在 https 上（自签也算）。

第 11 天 · 数据库入门

做什么（1.5–2 小时）

  • 装 MariaDB/MySQL，mysql -u root -p 进去，建库建表插数据查数据。
  • 备份/恢复各做一次：mysqldump 导出、导回去。

读哪一节：

验收：能建库建表插 3 条数据，并成功备份+恢复。

第 12 天 · 让网站用上数据库

做什么（1.5–2 小时）

  • 写一个最简页面（PHP 或 Python）从数据库读数据并显示。
  • 顺手练：给数据库用户授权、限制只允许本机访问。

读哪一节：

验收：浏览器打开页面能看到数据库里的内容。

第 13 天 · 防火墙与 SSH 加固（拿分点）

做什么（1.5–2 小时）

  • 开防火墙只放 22/80/443；SSH 改端口、禁用 root 直登、换密钥登录。
  • 改之前先开第二个终端保底，别把自己关在门外。

读哪一节：

验收：能独立完成一份「最小暴露面」加固清单。

第 14 天 · 第 2 周复盘：从零跑通一遍

做什么（1.5–2 小时）

  • 新开一台机器，**不看教程**，把「域名 → 网站 → HTTPS → 数据库」完整跑一遍。
  • 把卡住的地方写进错题本（页面右下角会自动记）。

读哪一节：

验收：2 小时内独立交付一个带 HTTPS 的站点。

第 2 周检查：Nginx 改完配置后，正确的生效顺序是？
先验证语法再重载，是比赛和工作中都通用的习惯。

第 3 周 · 云平台（把东西搬到云上）

第 15 天 · 云平台第一天：控制台与区域

做什么（1.5–2 小时）

  • 登录 AWS 控制台（或用比赛指定的云平台），找到：区域切换、服务搜索、最近访问。
  • 先把区域切到离你最近的（如东京/新加坡）。

读哪一节：

验收：不看教程能在 30 秒内找到任意一个指定服务。

第 16 天 · IAM：账号与权限

做什么（1.5–2 小时）

  • 建用户、建用户组、给组挂策略、给用户配访问密钥。
  • 搞清根用户和 IAM 用户的区别（这是比赛和真实工作都考的）。

读哪一节：

验收：能说清「为什么不直接用根用户干活」。

第 17 天 · VPC 与安全组

做什么（1.5–2 小时）

  • 建一个 VPC + 子网 + 路由表 + 互联网网关，建安全组开放 22/80。
  • 画一张图：数据从公网进来经过什么。

读哪一节：

验收：能解释安全组和防火墙的区别。

第 18 天 · EC2：把服务器开到云上

做什么（1.5–2 小时）

  • 选镜像起一台实例，配好密钥对，SSH 进去。
  • 在云主机上重复第 4 天的操作：装 Nginx 并访问公网 IP。

读哪一节：

验收：15 分钟内从零起一台能访问的 Web 服务器。

第 19 天 · S3：对象存储与静态网站

做什么（1.5–2 小时）

  • 建桶、上传文件、开静态网站托管、访问桶的访问端点。
  • 练一次生命周期/权限设置。

读哪一节：

验收：能说清「S3 和 EBS 有什么区别」。

第 20 天 · 托管数据库与备份

做什么（1.5–2 小时）

  • 起一个 RDS（最小规格），连上去建表；做一次快照并了解恢复流程。
  • 顺手看账单页面，知道钱花在哪。

读哪一节：

验收：能说清快照和备份的区别、什么时候用哪个。

第 21 天 · 第 3 周复盘：把站搬到云上

做什么（1.5–2 小时）

  • 把第 2 周做的站点，整体搬到云上（EC2 + S3 + RDS 或最小组合）。
  • 限时 2 小时，超时也要产出。

读哪一节：

验收：限时 2 小时完成，并写出 5 行部署说明。

第 3 周检查：安全组和防火墙的区别，下面哪句对？
云上题目经常要求「两层都要配」，少配一层就不通。

第 4 周 · 真题与拿分（对准初级赛）

第 22 天 · 一条龙综合演练（初级赛的典型题）

做什么（1.5–2 小时）

  • 同一台机器上同时跑起来：Nginx 网站 + 数据库 + DNS 解析，并让它们互相打通。
  • 限时 90 分钟，不看教程；卡住才回去查。

读哪一节：

验收：90 分钟内从零交付「域名 → 网站 → 数据库」三件套。

第 23 天 · 排障专项：自己造坏再修好

做什么（1.5–2 小时）

  • 固定六步：① 现象 ② 看日志 ③ 查端口与服务 ④ 查配置 ⑤ 查资源 ⑥ 改回来验证。
  • 自己造 5 个故障：改坏 Nginx 配置、停掉服务、占满 80 端口、写错 hosts、权限改成 000，逐个修好。

读哪一节：

验收：拿到一个坏环境，能在 10 分钟内说出下一步看哪里。

第 24 天 · 命令盲测 + 口述演练（练表达）

做什么（1.5–2 小时）

  • 把常用的 30 条命令用白纸默写一遍，写不出的回去复习。
  • 对着手机录音，用 1 分钟讲清：「网站打不开，我怎么查」——比赛里裁判会问你思路。

读哪一节：

验收：能不看任何资料，边做边说清排查思路。

第 25 天 · 真题一 · 限时 2 小时

做什么（1.5–2 小时）

  • 拿一套真题，**限时 2 小时**做，模拟比赛节奏：不查答案、不求助。
  • 做完立刻记下：哪些没做完、卡在哪。

读哪一节：

验收：限时产出，哪怕只完成一半也要交卷。

第 26 天 · 真题复盘（5 问，当天必须写完）

做什么（1.5–2 小时）

  • ① 错在哪一步 ② 当时为什么那么想 ③ 正确的做法是什么 ④ 下次怎么识别这类题 ⑤ 重做计划。
  • 把 25 号没做完的题，第二天重做一遍。

读哪一节：

验收：5 问写完，且重做题能独立完成。

第 27 天 · 真题二 · 限时 3 小时 + 抗干扰

做什么（1.5–2 小时）

  • 限时 3 小时完整做一套；中途故意让自己被打断一次（模拟赛场干扰），看还接不接得上。
  • 做完按评分点自评打分。

读哪一节：

验收：有完整的时间分配策略：哪部分先做、哪部分保底。

第 28 天 · 赛前 24 小时清单

做什么（1.5–2 小时）

  • 准备：比赛环境确认、常用命令手册、账号密码、网络与打印机等外部条件。
  • 把三周的高频命令抄成一页 A4；把易错点写成 10 条。
  • 今天不学新东西，只过手册。早睡。

读哪一节：

验收：手里有一页自己写的命令手册 + 10 条易错点。

第 4 周检查：限时真题做完后，最该立刻做的一件事是？
世赛选手的共同做法是「问题不过夜」；不复盘的刷题只是重复犯错。

往上打的阶梯（你现在在哪一级）

初级
校赛 / 市赛 / 省选拔初赛		 Linux 基础操作（命令、权限、用户）→ 服务部署（Web / 数据库 / DNS）→ 简单网络配置 → 云平台开机器。
这 4 周练的就是这一级。别学超纲的东西，把这一级练到「闭着眼能做」最关键。
中级
省赛 / 国赛预选		 在上面基础上加：Windows Server + AD 域、负载均衡与高可用（Nginx/HAProxy/Keepalived）、Docker 容器、监控与日志。
晋级后学：第8章 Windows Server · 第6章 负载均衡 · 第10章 Docker
高级
国赛 / 世赛选拔		 Kubernetes 与编排、IaC（Ansible / Terraform）、CI/CD 流水线、全场景故障排查、成本与性能优化、SLO 意识。
再往上：第11章 K8s · 第13章 自动化运维 · WSOS 官方标准（权重表）

周期参考：初级从零到能打 ≈ 4–8 周；中级 ≈ 3–6 个月；高级 ≈ 12 个月以上（世赛选手备赛约 1000 小时）。 每打完一级再学上一级的东西，不要提前跳。

应急通道

只剩 7 天：D2 命令行走一遍 → D4 装 Nginx → D5 服务与日志 → D15 控制台 → D18 起 EC2 → D25 做一套真题 → D28 赛前清单。

只剩 3 天（72 小时）：直接用站里的 《72 小时冲刺作战手册》， 它的取舍比这份更狠。

明天就考：只看三张纸——常用命令 20 条、服务排障六步、云上开机器流程。今天早睡，考场上的清醒比多学一条命令值钱。

关于"能不能拿牌"

世赛级别的选手通常备赛 约 1000 小时，韩国选手日均训练 12 小时以上。4 周 = 50~80 小时， 现实目标应定在：完成基础模块、部署类题目拿到分、排障题能说出思路。

但你这 4 周练出来的方法（看日志、按套路排查、限时自测、当天复盘）是可迁移的—— 下一届、下一个赛项，都靠这套。所以别把它当"临时抱佛脚"，把它当第一次行军。
