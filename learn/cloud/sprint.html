③ 每天怎么过 · 三段制 + 三条铁律

时段干什么规则
上午 3h
学模板		看该题的真题解析 → 照抄一遍 → 改参数独立重做一遍（换 IP/换目录/换版本，比赛一定改）只学当天清单里的题，不越界
下午 4h
真题实操		对应模块真题限时裸做——不查资料像考试；做完对照标准答案/解析逐项自检单题卡住 ≤10 分钟就跳过，最后回头收拾
晚上 2h
闭卷验收		当天全部操作闭卷重做一遍（这是"会"变"稳"的唯一方法）→ 错题本记 ≥3 行 → 预习明日模板 15 分钟重做不过 = 明早第一件事再做
  • 🔨 铁律一：所有操作必须亲手敲。"看会"的部分考场上一个都想不起来，只有敲过的能留下。
  • ⏱ 铁律二：死磕不超过 10 分钟。卡住 → 速查卡找命令 → 再不行跳过。比赛比的是总分，不是单题自尊。
  • 🌙 铁律三：每晚闭卷重做 + 错题本。同样的坑只许踩一次；每周日把错题本从头复做一遍。

④ 考前必背 · 高频模板 Top 20（每个都对应一道真题原型）

  • 私有云 · 搭建链 13 小题：双节点基础环境 → Yum 源 → 免密 SSH → MariaDB 安装调优 → Keystone 建项目/用户/角色 → Glance 上传镜像 → Nova 规格/优化 → Neutron 网络 → Dashboard → Swift → Cinder 建盘。验收话术：任抽一题 5 分钟内报出"命令序列+验证命令"模板 1
  • Heat 编排创建用户/网络：hot 模板骨架背下来，考试只改参数模板 2
  • NFS 对接 Glance 后端 / Ceph 部署与 Glance·Cinder·Nova 三对接：对接三步曲（装客户端→改配置→重启服务+验证），Ceph 部署脚本背熟模板 3–4
  • Redis 主从 / 系统调优（脏数据回写、网络优化）/ KVM 优化：每题 5–8 行配置，默写级别模板 5–7
  • 排错两型（Neutron 网络组件 / Cinder 卷组件）：思路链背诵——systemctl status → journalctl -u 服务 -n 50 → 配置 diff → 修复 → 全链路复验模板 8–9
  • Shell 一键部署脚本 / Ansible 部署 ELK·Kafka：脚本骨架+playbook 骨架各背一套，考试改变量模板 10–11
  • kubeadm 部署 K8s 集群（含镜像源、网络插件、node 加入、dashboard/Harbor）：闭卷 30 分钟标准模板 12
  • YAML 四件套：Deployment+Service（NodePort）+ConfigMap+Ingress，背一组可改模板（教程第 11 章有两套）模板 13
  • 容器化部署 8 连：MariaDB/Redis/Nginx/ERP 容器化+编排、GitLab+Runner+Agent、CI/CD 流水线（.gitlab-ci.yml 骨架背熟）模板 14–16
  • 服务网格 Istio：VirtualService/DestinationRule 模板；KubeVirt：VMI 创建模板；审计日志：开启步骤模板 17–19
  • 华为云控制台路径 + KubeEdge 双端部署：ECS 购买→安全组放行→OBS 下载→RDS；cloudcore/edgecore 部署+systemd 管理+metrics（2023 B 卷原题，40 分大头）模板 20

⑤ 考场拿分策略 · 奖牌线是"少丢分"不是"多懂"

  • 📋 开考前通读全卷 10 分钟：每题标三档——【必拿】搭建/模板题（约 40–50 分）【争取】运维/排错题（约 30 分）【战略放弃或最后做】开发题难枝（约 10–15 分）。先保必拿档 100% 完成。
  • ⏳ 时间三三制：前 1/3 时间扫完所有必拿题 → 中 1/3 攻争取题 → 后 1/3 补漏+全链路复验。
  • ✅ 每题做完立即验证（curl/浏览器/kubectl get/systemctl status），别攒到最后一起飞。
  • 💾 改配置先备份：cp 配置 配置.bak ——排错题改崩了能回滚，这一条每年救回 2–5 分。
  • 🔁 改完必重启 + 必自启：systemctl restart && systemctl enable ——"开机自启"是评分脚本最爱查的隐形分。
  • 🚒 环境炸了不慌：恢复关键路径（网络→数据库→服务）优先，单点失败不纠缠；赛项一般允许重置虚拟机，重做模板题只要 20 分钟。
  • 🧾 交卷前 15 分钟检查单：所有服务 enable？防火墙端口？题目要求的密码/主机名改了没？浮动 IP/端口映射通不通？草稿纸逐题打勾对一遍——防漏题。
  • 🫀 心态：手抖正常；遇到全不会的题，把已知步骤写上去（很多评分点给过程分）。你比的是"谁丢分少"。
