② 30 秒搞懂：你比的是什么

不管哪个级别的云计算比赛，骨架都是三个模块（省赛/国赛同源，世赛线是公有云为主）：

  • 模块一 · 私有云（30-50 分）
    用开源 OpenStack 搭一套"内部云"：安装 MariaDB/Keystone/Glance/Nova/Neutron/Dashboard/Swift/Cinder 等组件 → 运维（Heat 编排/KVM 调优/Ceph 存储/Redis/排错）→ 写脚本自动化。考试形式：按任务书一步步做，脚本逐项验收，做对得分。    OpenStack
  • 模块二 · 容器云（30-50 分）
    用 kubeadm 搭 Kubernetes 集群 → 把数据库/网站/应用"容器化"部署 → GitLab + CI/CD 流水线 → 服务网格/虚拟机化加分面 → 排错。    K8s
  • 模块三 · 公有云（40 分，国赛）/ 省赛常为前两块
    云控制台上按题配置：VPC/云主机/数据库/安全组/负载均衡/弹性伸缩 → 容器引擎 → 边缘计算（KubeEdge）。世赛线则是 AWS 全线（EC2/S3/RDS/ECS/DynamoDB…）。    云平台
