第 0 步 · 先上零基础学堂

每条路线的第一段，都对应学堂里的一节零基础第一课：先花 5 分钟看清「这是什么、第一步做什么」，再进入下面的阶段计划。

→ 进入零基础学堂（9 节视频课 + 图文讲义）

云计算 · 从零到世赛（12 个月） · 先看学堂第一课

先把比赛看明白：世赛云计算（Trade 39）一届通常 4 个模块——Linux 系统 / Windows·AD / 公有云架构（AWS）/ 自动化与故障排查。 AWS 只是其中一块，所以这条路线的地基是 Linux 与网络，不是云。→ 比赛本身怎么考，看云赛页第一节

阶段 0 · 建地图（1 周）
读完云赛页「先读懂比赛本身」，知道 4 个模块各自考什么、评分脚本长什么样；确定自己主攻方向。
检查点：能口述每个模块的典型题面和评分点。
阶段 1 · 地基：Linux + 网络（2–3 个月）
命令行、用户权限、服务与 systemd、日志排查；TCP/IP、DNS、HTTP/HTTPS、防火墙、抓包。
材料：云赛页第 1–6 章 + 零基础学堂第一课。
检查点：不看教程独立搭出一台 Web 服务器 + 域名解析 + HTTPS 证书。
阶段 2 · AWS 公有云（2 个月）
先刷 AWS Educate 六门基础课（云计算入门 101 → 存储 / 计算 / 网络 / 数据库 / 安全入门），再读本站 AWS 管理控制台入门 · 中文全文，然后做四门动手课（用户数据处理 / EC2 Instance Connect 登录 Linux / EBS 快照 / CloudWatch）。
→ AWS Educate 71 门课程中文总目录
检查点：不看教程起一套 VPC + EC2 + S3 + RDS，并能说清区域与可用区的取舍。
阶段 3 · Windows 与 AD（1–2 个月）
AD 域控、组策略、DNS/DHCP 集成、文件共享与权限、委派管理。
世界赛与国赛都有这块，且是与 Linux 并重的评分模块。
检查点：从零建一个域，把客户端加域并按组策略下发配置。
阶段 4 · 自动化与 IaC（2–3 个月）
Shell / PowerShell 脚本 → Ansible → Terraform → CI/CD；再进容器与 K8s（韩国赛路线：EKS + ArgoCD + GitOps）。
检查点：用 Terraform 一键重建整套实验环境。
阶段 5 · 冲金（3 个月+）
拿韩国近五年真题（本中心 exam/ 题库）限时裸做 → 对照评分点复盘 → 循环。补上成本优化与 SLO 意识——韩国题面细到实例规格和 SLO 百分比。

配套资源：云计算备战中心（20 章教程 + 224 篇真题 + WSOS 权重表）· 实战训练场 · AWS 课程库 · 世赛视频馆 · 长期路线见本中心 README-总导航.md 的 L0–L10 十级体系。

算法竞赛 · 从零到冲金（12–24 个月） · 先看学堂「算法竞赛第一课」

阶段 0 · 编程语言（1 个月）
选 C++（竞赛主流）或 Python（上手快）。学变量/循环/函数/数组/字符串/结构体。
检查点：能独立写出「判断素数」「简单模拟题」。
阶段 1 · 基础算法与数据结构（2–3 个月）
排序、二分、前缀和、差分、栈/队列、链表、哈希；递归与搜索（DFS/BFS）。
做题：CF 800–1200 分题 200 道（用本中心的 Codeforces 索引按分数筛）。
检查点：CF 稳定做出 Div3 前 3 题。
阶段 2 · 进阶结构（3–4 个月）
树与图的遍历、最短路、最小生成树、并查集、堆、线段树入门、DP 入门（背包/线性）。
做题：CF 1300–1600；洛谷「普及/提高-」。
检查点：能独立完成图论基础题与经典 DP。
阶段 3 · 算法深化（3–6 个月）
DP 进阶（区间/树形/状压）、数论（gcd/素数/同余）、组合数学、字符串（KMP/Hash）、贪心证明。
做题：CF 1600–1900；开始打 CF/AtCoder 比赛（每周 1–2 场）。
检查点：CF 上蓝（1600+）。
阶段 4 · 冲金（6 个月+）
数据结构进阶、网络流、计算几何、高级 DP 优化；大量做题 + 比赛复盘（每场必写总结）。
目标：ICPC/CCPC 区域赛铜区起步，逐步向银/金推进。

配套资源：竞赛真题中心（ICPC WF 题解 · CF/AtCoder 全量索引 · 蓝桥/天梯/CCPC）；在线平台：Codeforces / AtCoder / 洛谷 / AcWing。

公务员 · 从零到上岸（3–6 个月） · 先看学堂「公考第一课」

第 1 个月 · 行测打地基
资料分析（速算与找数）→ 判断推理（图形推理用本中心题库，每天 20 题）→ 言语理解（每天 10 题 + 错词本）。
第 2 个月 · 申论方法论
五类题型逐个突破；每天 1 篇材料精读、每周 1 套完整申论。
第 3 个月起 · 刷题 + 套卷
上午行测套卷、下午申论；错题本只记「错因 + 识别方法」；常识每天 20 分钟。
冲刺 · 最后 30 天
全真模拟 + 错题三刷；保持做题手感，不追新题。

配套：公务员页（354 题图形推理 + 真题大库导航）。

专升本 · 从零到录取（6–12 个月） · 先看学堂「升学考试第一课」

信息准备
查清本省考试科目与参考教材（各省差异极大），锁定 1 所目标院校。
基础期（3–6 个月）
英语：词汇每日 50 个（用本中心的单词本功能）；高数/专业课：按章过教材 + 课后题。
强化期（2–3 个月）
真题按题型刷；建立错题档案；计科类重点攻克程序设计题。
冲刺期（1 个月）
套卷全真模拟；背诵类科目集中背诵（政治理论等）。

配套：升学考试页 →「辽宁专升本（计算机组）备考助手」（77 考点 + 316 题 + 单词本）。

高考 · 从零到高分（三年节奏） · 先看学堂「升学考试第一课」

高一
跟紧课本 + 国家中小学智慧教育平台同步课；建立错题本（从第一天起）。
高二
完成新课 + 第一轮系统复习；弱势科目每周额外 2 小时专攻。
高三
一轮（教材全覆盖）→ 二轮（专题突破）→ 三轮（套卷模拟 + 查漏）。
真题：先用 升学考试页 的真题卷自测，再对照平台课程补弱项。
心态
「把会做的做对」就是提分。考前一个月回归错题本与基础题。

全球学术 · 从「搜不到」到「独立研究」（3–6 个月） · 先看全球学术资源库（33 条）

这条路线的目标不是「会用一个数据库」，而是建立一套可复用的检索—获取—管理—写作流水线：知道去哪儿找、怎么找全、怎么拿到全文、怎么管住文献、怎么把证据写进文章。全部资源免费，国际站点标注「国际网络」。

阶段 0 · 建立检索地图（1 周）
分清三类入口：综合检索（Google Scholar / Semantic Scholar / OpenAlex）→ 学科库（PubMed / Europe PMC / RePEc / SSRN）→ 全文库（PMC / DOAJ / CORE / BASE）。
练三件事：布尔逻辑与字段限定、被引追踪（谁引了这篇）、相关推荐。
检查点：同一个题目，用三个入口各找到 5 篇，说明它们收录范围的差别。
阶段 1 · 找到全文（2 周）
先用 Unpaywall / CORE / BASE 找合法开放版本，再去 PMC / Europe PMC 下 PDF；预印本看 arXiv / bioRxiv / medRxiv / SSRN；学位论文用 OATD / NDLTD。
记住红线：不用盗版镜像——拿不到就馆际互借或邮件问作者。
检查点：给 10 篇「付费墙论文」找到合法全文，记录每条路径。
阶段 2 · 数据与证据（1 个月）
宏观：IMF / 世界银行 / OECD / Eurostat / FRED / 国家统计局；健康：WHO GHO；教育：UNESCO UIS；人道：HDX；调查微观数据：CGSS / CFPS / CHARLS / 世界价值观调查。
重点不是下载，而是口径：指标定义、年份、可比价、抽样方式，写进你的数据说明。
检查点：做一张跨三国、跨十年的可比指标表，并写明每个数字的出处与口径。
阶段 3 · 文献管理与写作（1 个月）
Zotero 建库（按主题分文件夹 + 标签 + PDF 标注）→ 用 Crossref 补全 DOI → 用 OpenCitations 看引用网络 → 按 GB/T 7714 或目标期刊格式导出。
同时建 ORCID，把成果挂上去。
检查点：一篇 3000 字综述，参考文献 30 条全部可溯源、格式统一。
阶段 4 · 独立研究（持续）
用 Open Syllabus 看名校同门课读什么；用 预印本追前沿；用 Google 数据集搜索确认选题有没有数据；把检索式、数据、代码、笔记留档，保证别人能复现。
检查点：产出一份可复现的研究包（问题—数据—方法—结果—局限）。

配套：全球学术·开放数据（33 条） · 社会主义实践研究中心（方法流水线可复用）· 资料中心（术语与写作章节）。

免费官方认证 · 从零到拿证（3–6 个月） · 先看国际认证资源库（16 条）

原则先说清：只走厂商官方免费路径，不买题库、不碰泄题；证书是门槛不是天花板，能拿出手的永远是作品与实操记录。先选一条线，不要同时开三条。

第 0 步 · 选线（1 天）
云与运维 → AWS Skill Builder / Google Cloud Skills Boost / Microsoft Learn；网络与安全 → Cisco NetAcad / TryHackMe / OverTheWire；AI 与数据 → IBM SkillsBuild / Google ML 速成课 / Hugging Face；办公与营销 → Trailhead / Skillshop。
检查点：写下一句「我三个月后要拿到哪一个证，用它换什么岗位」。
阶段 1 · 系统课打底（1–2 个月）
云线：Linux Foundation 的 Linux 入门 → 云厂商基础课（免费层）→ 官方文档；网络线：NetAcad 网络基础 → CCNA 系列；AI 线：Python → Google ML 速成课 → fast.ai 或 HF Course。
每天 1 小时，看完立刻动手，不做纯视频囤积。
检查点：每个模块产出一页笔记 + 一个可运行的小实验。
阶段 2 · 动手实验室（1–2 个月）
云：Skills Boost 实验 / 免费额度起一套真实环境；安全：OverTheWire Bandit → TryHackMe 免费房间；编程：Exercism 找导师评审 / Codewars 刷段位；全栈：Full Stack Open 或 Odin Project 做完一个项目。
检查点：一个能公开访问或能演示的项目，README 写清架构与踩坑。
阶段 3 · 拿证与作品（1 个月）
按官方考纲过一遍薄弱项 → 做官方样题 → 报名考试；同时把项目、徽章、证书汇总成一页「能力证明」页（GitHub Pages 即可）。
检查点：证书到手 + 一页作品集 + 三段能讲清的技术决策。
阶段 4 · 持续（每季度）
挑一个新技术（K8s / Terraform / RAG / 安全运营），用同样的「官方课 → 实验 → 作品 → 证书」闭环滚一遍；每年清一次过时证书。
提醒：免费额度会变，报名前以官方页面为准；本站只收官方入口。

配套：国际认证·官方培训（16 条） · 云计算认证地图（10 大认证的官方入口与免费备考）· 实战训练场。

路线为本中心原创整理，结合公开经验与官方资源；按自身情况随时调整节奏。
