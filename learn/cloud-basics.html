② 学习地图 · 六阶段，每阶段带过关标准

阶段 0 · 地基（第 1–2 周）｜Linux + 网络，不是云，是云下面的东西

学什么：Linux 常用命令、文件权限、systemd 服务管理、SSH；TCP/IP、IP 与子网、端口、DNS、HTTP/HTTPS 流程。

在哪学（全中文、全离线）：第 1 章 · Linux 零基础 · 第 2 章 · 网络零基础 · 知识地图 01 · 知识地图 02。视频：视频库里的 Docker/K8s 之外的通用课。

怎么练：VMware Workstation Pro（个人免费）或 VirtualBox 起一台 Rocky 9 / Ubuntu 24.04；实战训练场 L1 有任务书和自动评分脚本。

过关标准：不看任何资料，15 分钟内完成一台新机的初始化 + SSH 密钥登录 + 装 Nginx 并用 IP 访问成功。做不到就别往下走。

阶段 1 · 概念（第 3 周）｜先建立「云到底改变了什么」

学什么：IaaS / PaaS / SaaS 的边界；公有云 / 私有云 / 混合云；Region 与 Availability Zone；云的三种责任划分（IaaS/PaaS/SaaS 各自客户负责到哪一层）；计费模型（按需/预留/Spot/节省计划）。

在哪学：知识地图 04 · 虚拟化与私有云 · 精通体系总纲 · 疆域全景图（一张图看懂整个云的疆界，强烈建议先看这个）。
英文官方：Skill Builder 搜 Cloud Practitioner Essentials（免费课里最经典的一门）。

过关标准：能用自己的话讲清「为什么需要 AZ」「共享责任模型的分界线在哪」「为什么云不等于便宜」。

阶段 2 · AWS 账号与第一个服务（第 4 周）

学什么：注册账号（务必选对区域，选离你最近的，如东京/新加坡/宁夏）；根用户与 IAM 的区别（这是最该第一天就懂的事）；建第一个 IAM 用户与角色；开一台 EC2 并安全组放行。

官方入口：Skill Builder（免费层 1,000+ 学习资源、900+ 门自定进度数字课）· AWS Educate（免费、无需信用卡、13 岁+，但已不再发放抵扣金，只剩课程与实验）。

先读这个：本站已把 AWS 管理控制台入门官方课件全文（5 节 53 张幻灯片逐条对齐）离线化了 —— 不懂英文就先啃这个，免费且离线。

过关标准：能用 IAM 策略限制一个用户只能读不能写；能说出「为什么不直接用根用户干活」。

阶段 3 · 核心服务实操（第 5–7 周）｜本页 ⑤ 有逐个动手清单

学什么：EC2（计算）、S3（对象存储）、VPC + 子网 + 安全组（网络地基）、ELB（负载均衡）、RDS（托管数据库）、Lambda（无服务器）、CloudWatch（监控）。

在哪学：第 12 章 · AWS 云平台实战（全中文保姆级）· 知识地图 05 · 公有云核心（AWS）（最硬核的一篇，含 WSOS 考纲对应考点）。

怎么练：AWS Workshops（已迁至 Builder Center，203 个，零基础只挑 100 级） + 本页 ⑤ 的五分钟最小实验。

过关标准：能徒手画出一张 VPC 拓扑图（公私子网、路由、IGW/NAT、安全组方向），并说清公网请求打进来会依次经过什么。

阶段 4 · 容器与编排（第 8–9 周）

学什么：Docker 镜像/容器/网络/卷 → Kubernetes 的 Pod/Deployment/Service/Ingress → 从 minikube 到 HPA。

在哪学：第 10 章 · Docker 容器入门 · 第 11 章 · K8s 入门 · 知识地图 06 · 实训场 L3 Docker / L4 Kubernetes（带自动评分）。
视频：阿里云 × CNCF 云原生公开课（30P/13h28m，官方声明全程免费且无需注册）。

过关标准：能把一个应用打镜像 → 推仓库 → 用 Deployment 起多副本 → 用 Service 暴露 → 故意删掉一个 Pod 看自动恢复。

阶段 5 · 自动化与可观测（第 10–11 周）｜从「会摆」到「会交付」

学什么：Shell 脚本三件套 → Ansible（批量配置）→ Terraform（代码即基础设施）→ CloudFormation → CloudWatch 告警与日志 → CI/CD 一条龙。

在哪学：第 9 章 · Shell 进阶 · 第 13 章 · 自动化运维 · 知识地图 07 · 自动化与 IaC · 知识地图 08 · 可观测性 · 精通体系 · 架构模式手册。

过关标准：一份 Terraform 能从零把整套环境建出来，销毁再建结果一致（幂等）；删掉一台机器能收到告警。

阶段 6 · 架构视野与自检（第 12 周）

学什么：Well-Architected 六支柱（本页 ③ 逐条展开）· 高可用与故障转移 · 成本优化 · 安全基线。

自检：Skill Builder 免费层的 Official Practice Question Set（每套 20 题、含详细讲解，是官方唯一免费的模拟题来源）· 本站 睡前考场随机出题 · 学堂自测。

过关标准：用 Well-Architected Tool（控制台里免费可用）给自己的环境跑一次评估，能指出至少 5 条高风险项并说清改法。

B. Well-Architected Framework（架构观的底座，官方免费）

官方定位：「通过回答一组基本问题，了解你的架构与云端最佳实践的符合程度。」六大支柱（官方原文口径）：

  • 卓越运营 Operational Excellence —— 运行与监测系统、持续改进流程与程序。关键主题：自动化变更、响应事件、定义标准来管理日常运营支柱1
  • 安全性 Security —— 保护信息与系统。关键主题：数据机密性与完整性、管理用户权限、建立检测安全事件的控制支柱2
  • 可靠性 Reliability —— 工作负载执行预期职能、故障后快速恢复以满足需求。关键主题：分布式系统设计、恢复计划、适应需求变化支柱3
  • 性能效率 Performance Efficiency —— 有序流畅地分配 IT 与计算资源。关键主题：选择适配工作负载的资源类型与规模、监测性能、随业务演进维持效率支柱4
  • 成本优化 Cost Optimization —— 避免不必要的成本。关键主题：了解支出趋势并管控资金分配、选择合适类型与数量的资源、不超支地扩展支柱5
  • 可持续性 Sustainability —— 减少云工作负载的环境影响。关键主题：可持续性责任共担模式、了解影响、最大化资源利用率以减少所需资源支柱6

六大支柱之外，还有三样东西很多人不知道：

  • Well-Architected Lenses（详解/聚焦） —— 把框架落到具体领域：机器学习、数据分析、Serverless、高性能计算、IoT、SAP、流媒体、游戏、混合网络、金融服务、数字主权、生命科学、Telco、Microsoft 工作负载、Agentic AI 等。多个 Lenses 可叠加使用Lenses
  • Well-Architected Tool —— 在 AWS 管理控制台内免费获取，定期评估工作负载、识别高风险项、记录改进免费工具
  • ⚠️ Well-Architected Labs 要小心：站点 wellarchitectedlabs.com 仍在线，但侧栏那个「100 Labs」索引页实际只剩 1 个实验（Automating Serverless Best Practices with Dashbird）。完整实验代码与内容以 GitHub awslabs/aws-well-architected-labs 为准（2000+ star，2026-01 仍在更新）——想做的实验直接去 GitHub 找已缩水

Guidance（专项指南）：基于单元的架构缩小影响范围 · DevOps 指南 · 云端变更支持 · 运营就绪性审查（ORR）· 管理与监管云环境指南 · 云中的工作负载灾难恢复。这些是白皮书，可离线。

入口：Well-Architected 中文总览 · 框架文档 AWS 文档（繁中）。官方说明：不同支柱之间要按业务需求做取舍——开发环境可以为省钱牺牲可靠性，关键任务系统可以为可靠性接受更高成本，但安全性与运营绩效通常不会被牺牲。这句话本身就是一道面试题。

④ 免费额度实况 + 防超费红线

AWS Free Tier 官方现状（2026-10 核实）：

  • 「30+ AWS services are always free within monthly usage limits」——30+ 服务在月度用量限额内永久免费（Free 计划与 Paid 计划均适用）永久
  • 新账户：立即到账 $100 抵扣金，探索过程中最多可再赚 $100 —— 6 个月内共 $200，可覆盖 90+ 服务随便折腾$200
  • 「账户在开启 6 个月后、或抵扣金用尽时（以先到者为准）自动关闭」；除非你主动转成 Paid 计划，否则不会被扣费安全

🚨 真正会扣钱的三件事（新手 100% 中招）

  • 转成 Paid 计划 —— 上面那句「不会扣费」的前提是你一直待在 Free 计划。为了「以后方便」点一下升级，是账单爆掉最常见的原因。
  • NAT Gateway —— VPC 本身免费，但每个 NAT 网关按小时收费。EC2 装完 apt 走 NAT 出去下东西，一晚上几毛钱；放着不管一个月就是几十块。不用就删。
  • Elastic IP（弹性公网 IP） —— 未关联、或关联在已停止实例上，同样按小时计费。做完实验记得释放。

另外：RDS 的免费实例有规格与时长限制，超出即按正常单价（比 EC2 贵一个量级）；EC2 的免费额度是「每月若干小时 × 若干个月」，用完按 On-Demand 单价走。AWS 的实例类型/规格定价页很复杂，开非 t2/t3.micro/small 之前先看价格。

三道保险（做完第一件事就设）

  • ① AWS Budget 预算告警 —— 控制台 Billing → Budgets，新建 $1 或 $5 预算并开启邮件告警，阈值一到立刻收到通知必设
  • ② Cost Anomaly Detection —— 异常消费自动检测告警，比预算告警更早发现问题强烈
  • ③ 养成「用完就删」的习惯 —— NAT GW、弹性 IP、临时 RDS 实例、快照，都是「忘了删就持续计费」的重灾区。建议每周末花 5 分钟看一次 Cost Explorer习惯

入口：aws.amazon.com/free · 预算与告警在 Billing 控制台。本页不推销任何付费服务，30+ 永久免费服务请以官方定价页当日额度为准——额度可能调整，开资源前建议再核一次。

⑤ 六大主力服务 · 五分钟最小实验

每个都给「最小可跑通实验 + 验证方式 + 学到什么」。全部在 Free Tier 额度内。

  • ① EC2（计算） —— 起一台 t3.micro Ubuntu，用密钥对登录（不要用密码）；装 Nginx；浏览器访问公网 IP。
    验证：页面能打开。学到：实例/AMI/安全组/User Data/区域与 AZ 的区别    必做
  • ② S3（对象存储） —— 建桶 → 上传一个文件 → 开启静态网站托管 → 访问对象端点 → 再试一次：不开公共读，访问会 403。
    验证：403 那一刻你就懂 S3 权限了。学到：桶策略/ACL/公共访问阻断/生命周期，与 EBS 的本质区别    必做
  • ③ VPC + 安全组（网络地基，最重要） —— 建 VPC → 两个子网（公网/私网）→ 路由表 + IGW → 安全组开 22/80 → EC2 放进去。
    验证：画出这张图给同学看。学到：子网/路由/安全组有状态与 NACL 无状态/为什么公私子网要分    最重
  • ④ Lambda（无服务器） —— 建函数，把 S3 上传事件当触发器，上传文件看函数日志。
    验证：控制台实时打印文件名。学到：事件驱动/免运维/并发与限额/与 EC2 的取舍    易上手
  • ⑤ RDS（托管数据库） —— 建最小规格实例，连上去建库建表插数据。
    验证：务必做完就删实例。学到：与自建 MySQL 的差异、备份快照、为什么它比 EC2 贵    小心计费
  • ⑥ ELB 负载均衡 + ASG 自动伸缩 —— 两台 EC2 挂到 ALB 后面；再挂 ASG，设目标追踪。
    验证：访问 ALB 地址来回几次，看后端轮换；手动扩一台看是否被自动缩掉。学到：健康检查/会话/弹性/可用区分布——世赛可靠性 15% 权重考的就是这套    高分项

⑥ 没有 AWS 账户 / 网络受限怎么办

学云不一定要有云账户。这几条替代路线完全离线，概念一点不打折：

  • 本地虚拟机 —— VirtualBox / VMware Workstation Pro（个人免费）装 Rocky 9 或 Ubuntu 24.04，把「服务器」跑在自己电脑上。站点 实训场的三套环境方案就是这么设计的首选
  • LocalStack —— 在 Docker 里跑一套 AWS API 兼容的本地云，S3/SQS/Lambda/DynamoDB 都能调，断网可用，最适合练「API 调用」而不是「控制台点点」API
  • MinIO —— S3 兼容的对象存储，一条命令本地跑起来，练习桶/权限/生命周期几乎等价替代S3
  • DynamoDB Local —— 官方提供的本地版，Java 一跑就有，NoSQL 建模不用花钱替代DDB
  • minikube / kind / k3s —— 本地 K8s 集群，一条命令起来，断网也能练 K8s；离线装镜像需要提前拉包替代K8s
  • OpenStack（社区版） —— 国内国赛私有云路线就是这个；但要注意与 AWS 公有云路线是两回事，别混着学私有云
  • eNSP —— 华为官方免费网络仿真工具，完全离线可用，练网络最省心离线

国内网络环境下的免费云主机还有：阿里云免费试用（⚠️ 每个账号只有一次试用权益、时间无法延长，需实名）· 华为云免费试用 · 腾讯云免费试用 · 云起实验室 developer.aliyun.com/adc（免费沙箱，⚠️ 注意正确入口是 /adc/，老的 lab.aliyun.com 已失效）。
