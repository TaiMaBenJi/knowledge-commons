# 术语层（docs/glossary）

## 这一层解决什么问题

本站内容几乎全是中文，但**顶层能力只能靠一手英文资料喂养**：
AWS 官方文档、Google SRE Book、CNCF 博客 —— 全是英文。

体检结论（2026-10-14，全库关键词统计）：`zero trust`、`well-architected`、
`service mesh` 的英文原形在正文里**近乎为零**。

**这不是小事，它会直接卡死你**：官方文档写 `throttling` 和 `quota`，
你只记得中文「限流」，用中文去搜英文资料 —— **搜不到，因为英文资料上
根本没有"限流"这两个字**。认不出英文原词 = 在英文世界失联。

这一层就是补这个洞的。

## 收录标准

| 要 | 不要 |
|---|---|
| **英文原词必须准确**（官方文档里的写法） | 中文音译（`萨迪斯`） |
| 对齐 **T1–T10 十层**结构 | 按字母排（按层排才用得上） |
| 标注**站内覆盖情况**（✅ 有 / 🟡 提纲 / ❌ 站外补） | 假装全都有 |
| 一句话说清「它是什么 + 为什么值得记」 | 抄词典定义 |

> **最重要的一条**：宁可留一个待核实的标记，也不要自造译词。
> 自造词在英文资料里搜不到，等于**制造新的检索障碍**，比不写还糟。

## 怎么用（具体动作）

1. **学新概念时顺手搜一次英文** —— 在 `study.html` 里搜英文原词定位站内章节，
   再用同一个词搜官方资料，两边对得上号。
2. **卡住时先怀疑"词不认识"**，不是"概念不懂"。
3. 只记三个的话：`throttling`、`idempotent`、`least privilege`。
