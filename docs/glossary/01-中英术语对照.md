# 中英术语对照表（云计算 · 世赛 → 顶层架构）

> **这份表为什么存在**
>
> 本库内容几乎全是中文，但**顶层能力只能靠一手英文资料喂养**：
> AWS 官方文档、Google SRE Book、CNCF / CNCF 博客、Kubebuilder Book —— 全是英文。
>
> 典型卡壳场景：官方文档里写 `throttling` 和 `quota`，你只记得中文「限流」，
> 搜 "限流" 搜不到任何东西 —— **因为英文资料上根本没有"限流"这两个字**。
>
> **认不出英文原词 = 在英文世界失联。** 这张表就是那份词典。
>
> **用法**：每学一个概念，在这里记下英文原词（几秒钟）。
> 查英文资料时用英文原词去搜。

## T3 · 排障与故障处理 ← **世赛投入产出比最高的一层**

> TD53：四天赛程约 **3/4** 是排障。WSOS 权重里「问题解决 20% + 安全 20% + 可靠 15%」也压在这一带。

| 中文 | English | 一句话 |
|---|---|---|
| 故障排除 | troubleshooting | |
| 根因分析 | RCA (root cause analysis) | 不是"谁写错了"，是"哪个条件没被守住" |
| 平均修复时间 | MTTR (mean time to repair) | 越小越好 |
| 平均故障间隔 | MTBF (mean time between failures) | 越大越好 |
| 服务等级指标 | SLI (service level indicator) | 可量化的那个数，如成功率、延迟 |
| 服务等级目标 | SLO (service level objective) | 给 SLI 定目标值 |
| 服务等级协议 | SLA (service level agreement) | 对外承诺，有法律效力 |
| 故障预算 | error budget | `(1 - SLO) × 总量`，花完了就别再冒险发布 |
| 事故 | incident | 线上真实故障 |
| 事后复盘 | postmortem | 事故后分析 |
| 无指责复盘 | blameless postmortem | **只追机制不追人** —— 人才是改不动的那一环 |
| 操作手册 | runbook | 出事了照着做的那份文档 |
| 值班 | on-call | 出事第一个接电话的人 |
| 可观测性 | observability | 从外部输出推断内部状态的能力 |
| 关联 ID | correlation ID / trace ID | 一次请求跨服务的唯一标识 |

## 怎么用这份表（具体动作）

### 1. 学新概念时，**顺手搜一次英文**

在 `study.html` 里搜英文原词，能定位到本站讲这个概念的章节；
再用同一个词去搜 AWS / Google SRE 官方资料，**两边对得上号**。

### 2. 卡住时，先怀疑是"词不认识"，不是"概念不懂"

中文资料讲"限流"，英文资料写 `throttling`。
不知道这个词 = 在英文世界**根本搜不到**。这是最常见、也最容易补的差距。

### 3. 三个最值得先记的词

如果只记三个，记这三个 —— 它们出现在几乎所有架构文档里：

| 词 | 为什么 |
|---|---|
| `throttling` | 限流。AWS 控制台和报错里全是它 |
| `idempotent` | 幂等。分布式系统的核心词 |
| `least privilege` | 最小权限。安全章节的起点 |

### 4. 常见缩写速查

| 缩写 | 全称 | 中文 |
|---|---|---|
| SLA / SLO / SLI | service level agreement / objective / indicator | 服务等级协议 / 目标 / 指标 |
| MTTR / MTBF | mean time to repair / between failures | 平均修复时间 / 平均故障间隔 |
| RTO / RPO | recovery time / point objective | 恢复时间 / 恢复点目标 |
| HA / DR | high availability / disaster recovery | 高可用 / 容灾 |
| CI / CD | continuous integration / delivery (or deployment) | 持续集成 / 持续交付 |
| IaC | infrastructure as code | 基础设施即代码 |
| RBAC / ABAC | role- / attribute-based access control | 基于角色 / 属性访问控制 |
| CA / PKI | certificate authority / public key infrastructure | 证书颁发机构 / 公钥基础设施 |
| DNS | domain name system | 域名系统 |
| LB | load balancer | 负载均衡 |
| VM | virtual machine | 虚拟机 |
| PDP / PEP | policy decision / enforcement point | 策略决策 / 执行点 |
