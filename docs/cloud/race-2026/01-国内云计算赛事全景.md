**2026 版新增的可持续发展（Sustainability）Section 具体考点**（原文提炼）：
- 云计算可持续性目标与本质（如减少每次操作/架构事务所需资源）
- 最大化可持续性、最小化环境影响的工作负载架构设计原则
- 估算工作负载未来影响的方法；影响来源（客户使用、最终退役）
- 将生产产出与「每单位工作的资源与排放影响」对比的方法学
- 可持续性 KPI 的用途、方法及提升利用率的原理
- 硬件/软件快速创新对云工作负载设计的影响；共享托管服务对广泛客户群的影响
- 为特定产品建立 KPI、评估达成选项（含成本影响）并估算相对影响

**2026 版职业角色描述已重构**（原文）：新增/强调 **Cloud Architect（云架构师）、DevOps Engineer（DevOps 工程师）、Cloud Developer（云原生开发者）、Cloud Security Engineer（云安全工程师）** 四类角色，职责涵盖架构设计、基础设施自动化（IaC、代码部署、测试）、Serverless/微服务/容器化原生应用开发、云安全防护、工作负载迁移、**云成本优化**。→ 对做「云原生专区」内容规划非常关键：官方叙事已从「传统运维」转向「DevOps + 云原生开发 + FinOps」。
