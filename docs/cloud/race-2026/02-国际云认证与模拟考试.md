### 7.4 方法论局限

- 本次调研中 **`aws.amazon.com` 与 `cloud.google.com` 从沙箱直连失败**（前者 web_fetch 报 file load failed，后者返回 503）。AWS 部分结论依据**搜索引擎返回的官方页面完整正文**（可信度仍高），GCP 部分同理。
- 认证状态**变动频繁**（2026 年内 AWS、阿里云、Azure 三家均有大规模调整）。建议「知识公社」建立**季度复核机制**，并在每个认证条目上标注「核实日期」。

## 8. 给「知识公社」云计算专区的落地建议

1. **首屏就放第 0 节的 13 个陷阱**，而不是先放资源列表——这是本报告最高的用户价值。
2. **离线资产优先级**（按「可完全离线 + 官方 + 免费」三重筛选）：
   - AWS 考试指南 PDF + 官方样题 PDF + Well-Architected 白皮书 + 服务 FAQ
