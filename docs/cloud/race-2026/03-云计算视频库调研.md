### 0.1 本次调研如何取数

| 平台 | 取数方式 | 说明 |
|---|---|---|

| **YouTube** | `noembed.com/embed?url=`（代理调用 YouTube oEmbed 端点） | ⚠️ 见下方环境限制 |
| **厂商官网** | `web_search` + `web_fetch` | 逐页打开，记录原文证据 |

### 0.2 ⚠️ 本次调研的环境限制（影响国际板块的证据等级）

**本执行环境的出网被限制，`youtube.com` / `m.youtube.com` / `youtube-nocookie.com` 全部返回 000/503 连接失败，`web_fetch` 对 YouTube 页面返回 `file load failed`。**

后果：
- **可以做到的**：通过 `noembed.com`（第三方 oEmbed 代理，服务端调用 YouTube oEmbed API）确认视频**真实存在、拿到逐字准确的官方标题和频道名**。这是真实请求，反映 YouTube 当前数据。
- **做不到的**：**无法获取 YouTube 的播放量与时长**，因为这两项只在 watch 页 / Data API 里，而这两条路径都被墙。
- 因此「国际英文」板块的 YouTube 条目**均标 ⚠️ 存疑**，不代表链接失效，而是我无法在本环境验证播放量。

**给使用者的建议**：国际板块的链接可信（noembed 命中即视频真实存在），但播放量需在可访问 YouTube 的网络里自行补一次。
