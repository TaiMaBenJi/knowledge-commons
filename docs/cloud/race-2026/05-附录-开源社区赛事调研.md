> **【重大发现，先说结论】任务清单里的若干前提本身不成立：**
> 1. **KCTF ≠ 容器安全挑战赛**。KCTF 是**看雪学苑**的二进制逆向/漏洞攻防赛，**与容器/K8s 无关**。真正的 K8s CTF 是美国 DEF CON 的 *Kubernetes CTF*（非中国区）。
> 2. **「龙蜥开源大赛」不存在**。龙蜥不自办冠名大赛，模式是"到别人赛里出题"（研究生OS大赛、大学生系统赛）+ 自办**学习赛/训练赛**。真实名称是「**人人可以参与开源**」学习赛。
> 3. **「DevOps 挑战赛」中国区未找到**同名全国级赛事。最接近的是 IDCF 的**线下付费**「DevOps 黑客马拉松挑战赛」，属企业内训性质。
> 4. **「腾讯云 CODING DevOps 大赛」未找到**。腾讯云真实的赛牌是「**腾讯云黑客松**」（含 Agent 应用创新高校赛 / AI Coding 高校挑战赛）。
> 5. **KubeCon China 是会议，不是竞赛**（详见第 4 节，已按要求确认并标注）。

## 4. KubeCon + CloudNativeCon China —— **确认：这是技术会议，不是竞赛**

### 4.1 性质确认 ✅
> CNCF 官网原文：「CNCF… **runs the largest open source developer conferences in the world**」；KubeCon + CloudNativeCon 页面描述为「The Cloud Native Computing Foundation's **flagship conference** gathers adopters and technologists」；LF Events FAQ 明确「KubeCon + CloudNativeCon China 2025 **will take place in person from 10-11 June**.
